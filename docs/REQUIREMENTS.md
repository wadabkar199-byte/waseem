## 1. نظرة عامة على المشروع (Project Overview)
**وسيم (WASEEM)** هي منصة رقمية رائدة ومتكاملة لحجز خدمات الحلاقة والعناية بالرجال، تهدف إلى إحداث نقلة نوعية في تجربة العميل اليومية ورفع كفاءة إدارة صالونات ومحترفي الحلاقة.
- **الشعار اللفظي:** "إطلالتك تبدأ من هنا - منصة حجز الحلاقة الذكية".
- **الهوية البصرية:** الأخضر الداكن الملكي (`#123D32`)، الذهبي الراقي (`#F0D49A`)، وخلفيات عاجية/أبيض كريمي (`#F8F9FA` / `#FAF8F5`). واجهة عربية كاملة بتخطيط RTL.

## 3. المتطلبات الوظيفية حسب الأدوار (Functional Requirements)

### 3.1 دور العميل (Client)
1. **المصادقة والتسجيل:**
   - إنشاء حساب بالبريد الإلكتروني / كلمة المرور أو تسجيل الدخول الاجتماعي (Google / Apple).
   - استعادة كلمة المرور وإدارة الحساب الشخصي.
2. **الاستكشاف والبحث المتقدم:**
   - استعراض صالونات الحلاقة القريبة والموصى بها على الصفحة الرئيسية.
   - تصفية وبحث متقدم حسب: اسم المحل، المنطقة/الحي، نوع الخدمة، التقييم، ونطاق الأسعار.
   - استعراض العروض الحصرية ("عروض وسيم").
3. **الملف التعريفي للصالون / الحلاق:**
   - عرض تفاصيل الصالون، الصور، أوقات العمل، قائمة الخدمات مع الأسعار والمدد المتوقعة، وتقييمات العملاء الموثقة.
   - إضافة/إزالة الصالونات من قائمة المفضلة.
4. **مسار الحجز الذكي (Booking Flow):**
   - اختيار الخدمات المطلوبة (خدمة واحدة أو باقة خدمات متعددة).
   - اختيار الحلاق المحدد داخل الصالون (أو خيار "أي حلاق متاح").
   - اختيار التاريخ والوقت المتاح بدقة بناءً على التوفر اللحظي المؤكد من الخادم.
   - مراجعة تفاصيل الحجز وتطبيق كوبونات/عروض الخصم إن وُجدت.
   - اختيار طريقة الدفع (دفع نقدي عند الوصول في المحل، أو بطاقة/محفظة رقمية).
   - تأكيد الحجز واستلام إشعار التأكيد ورقم الحجز المرجعي.
5. **إدارة الحجوزات والمتابعة:**
   - تبويب "حجوزاتي" مقسم إلى: (قادمة Upcoming، سابقة Past، ملغاة Cancelled).
   - إمكانية إلغاء الحجز وفق سياسة الإلغاء المعتمدة.
   - تقييم الخدمة وكتابة مراجعة بعد اكتمال الموعد بنجاح.
6. **الملف الشخصي والإعدادات:**
   - تعديل البيانات الشخصية، تفضيلات الإشعارات، وتغيير كلمة المرور.
   - شاشات المساعدة والدعم الفني، وسياسة الخصوصية والشروط والأحكام، وخيار حذف الحساب.

---

### 3.2 دور الحلاق / صاحب الصالون (Barber / Shop Owner)
1. **التسجيل والاعتماد المهني:**
   - تسجيل حساب كمزود خدمة / حلاق، وتقديم بيانات الصالون أو الملف المهني.
   - رفع الوثائق وصور العمل للتحقق، وحالة الحساب تكون (`pending_review` قيد المراجعة) ولا يظهر الصالون في البحث العام إلا بعد اعتماد الإدارة (`approved`).
2. **إدارة الخدمات والتسعير:**
   - إضافة وتعديل وتصنيف الخدمات (قص شعر، تشذيب لحية، صبغة، عناية بالبشرة، باقات خاصة).
   - تحديد السعر والمدة الزمنية الدقيقة لكل خدمة (Duration بالدقائق، مثلاً 30 دقيقة).
3. **إدارة جدول المواعيد والتوفر:**
   - ضبط أوقات العمل الأسبوعية وساعات الفترات الصباحية والمسائية.
   - ضبط فترات الراحة (Breaks) والإجازات السنوية أو الطارئة.
4. **إدارة الحجوزات والعمليات اليومية:**
   - جدول زمني تفاعلي يوضح مواعيد اليوم والمواعيد القادمة.
   - تحديث حالة الحجز دورياً: (`confirmed` مؤكد، `in_progress` جارٍ التنفيذ، `completed` مكتمل، `cancelled` ملغى، `no_show` لم يحضر).
   - تحديث حالة استلام الدفع النقدي (Cash Collected).
5. **إدارة العروض والخصومات:**
   - إنشاء عروض ترويجية مخصصة للصالون (نسبة خصم، خصم بمبلغ محدد، تاريخ بداية ونهاية، سقف الاستخدام).
6. **لوحة المؤشرات والتقارير المالية:**
   - متابعة الإيرادات المسجلة، المبالغ المحصلة فعلياً، عدد الحجوزات المنفذة، وتقييمات العملاء.

---

### 3.3 دور مدير النظام (Admin)
1. **تسجيل دخول آمن ومحمي:**
   - مصادقة قوية للوصول إلى لوحة التحكم الإدارية عبر الويب (`admin/`).
2. **اعتماد وإدارة الصالونات والحلاقين:**
   - مراجعة طلبات الانضمام الجديدة والوثائق المرفوعة، مع صلاحية القبول، الرفض، أو الإيقاف المؤقت (`suspended`).
3. **إدارة المستخدمين والأدوار:**
   - استعراض كافة حسابات العملاء والحلاقين، وحظر أو إلغاء حظر الحسابات المخالفة.
   - فرض الصلاحيات عبر سياسات الأمان RLS على مستوى قاعدة البيانات مباشرة.
4. **إدارة المحتوى المركزي والتصنيفات:**
   - إدارة المناطق والمدن والأحياء المدعومة.
   - إدارة التصنيفات الرئيسية للخدمات والشارات (Badges) مثل: موصى به، الأفضل تقييماً.
5. **إدارة البلاغات والنزاعات:**
   - تلقي بلاغات المستخدمين أو شكاوى الحجوزات ومراجعتها والبت فيها.
6. **سجل التدقيق والمراقبة (Audit Log):**
   - تسجيل العمليات الإدارية الحساسة لضمان الشفافية والأمان.
7. **التحليلات والمؤشرات الشاملة للمنصة:**
   - إجمالي الحجوزات النشطة والناجحة، إجمالي الحجم المالي المتداول، ومعدلات نمو المنصة.

## 4. المتطلبات غير الوظيفية (Non-Functional Requirements)

| المجال | المتطلب والمعيار |
| :--- | :--- |
| **الأداء والسرعة (Performance)** | - زمن استجابة الـ API أقل من 300ms في 95% من الطلبات العادية.<br>- وقت بدء التطبيق (App Launch Time) أقل من ثانيتين على الأجهزة المتوسطة. |
| **التزامن ومنع التعارض (Concurrency)** | - منع تضارب الحجوزات نهائياً (Race Conditions) بحيث يستحيل حجز المقعد نفسه في التوقيت نفسه لأكثر من عميل. |
| **الأمان والخصوصية (Security & Privacy)** | - تفعيل Row Level Security (RLS) بنسبة 100% على كافة جداول قاعدة البيانات.<br>- تشفير كلمات المرور وتأمين الاتصال عبر HTTPS/WSS.<br>- حظر تخزين أي مفاتيح سرية (`service_role`) في تطبيق الهاتف.<br>- تطبيق التحقق من صحة المدخلات ونوع وحجم الملفات المرفوعة من جهة الخادم. |
| **التواجد والموثوقية (Availability)** | - دعم وضع الاتصال الضعيف (Offline/Weak Connection Graceful Degradation) مع التخزين المؤقت للبيانات الأساسية وتجربة مستخدم مريحة. |
| **التوافقية وتجربة المستخدم (UI/UX)** | - دعم كامل للغة العربية وتخطيط RTL متقن.<br>- توافق الشاشات وأحجام الهواتف الذكية (Android 6.0 وما فوق). |
| **القابلية للتوسع (Scalability)** | - هيكلية كود نظيفة ومفصولة وقاعدة بيانات علائقية مهيكلة بفهارس دقيقة تدعم نمو المستخدمين دون تراجع الأداء. |
